Lista Query

Cole a lista de IDs abaixo, um por linha. A ferramenta extrai apenas os números, mesmo que haja texto junto, e une tudo separado por vírgula.

ID Comparação

Cole uma lista de IDs em cada campo (como um PROCV no Excel ou LOOKUP no Sheets). A ferramenta retorna apenas os IDs que aparecem nas duas listas, com a quantidade e a listagem. IDs repetidos são contados uma única vez.
